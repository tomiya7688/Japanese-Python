# v0.1 文法決定記録

状態: 文法決定版。規範は [JPy-v0.1.md](../spec/JPy-v0.1.md)。この記録は採用理由と互換性上の注意を説明する。

## 汎用forを「繰り返し」に統一

正式形は `繰り返し 対象 を 式 から:`。リスト・辞書・文字列・ジェネレーター・enumerateを個別構文にせず、通常のPythonの反復可能オブジェクトとして扱う。`各` は既存ソース向けの互換表記として維持する。日本語語順の新しい同義語を増やさない。

範囲forには `増分 ずつ` を追加する。`繰り返し i が 5 から 0 まで -1 ずつ:` は `range(5, 0, -1)` に対応する。終了値は含めず、暗黙に終了値へ1を加えたり降順を推測したりしない。`range` の名前解決を隠れた組み込み参照に置換しない。

## 基本文を補完

| 追加・確定 | 理由 |
|---|---|
| `使う 式 として 対象:` → with | ファイル専用ではなく、リソース管理全般を表す |
| `例外を起こす [例外]` → raise | 通常の日本語で「例外を発生させる」と読める。旧 `投げる` も維持 |
| `確認する 条件[, メッセージ]` → assert | Pythonの表明と一対一に対応する |
| `それ以外:` → else | ifだけでなくループ・tryのelseにも同じ表記を使う |

日本語形のwithは1項目とし、複数項目はPythonのwithを使う。例外原因の指定は `from`、別名の `as` もそのまま使える。assertの最適化時の省略を変更しないため、必須の入力検証に使う構文ではない。

## 「未決定」のままにしない範囲決定

非同期、ジェネレーター、パターンマッチ、内包表記、from-import、global/nonlocal/del、except*、型・論理演算子・組み込み関数は **v0.1ではPython表記を使う**。すべてを一度に日本語化して式文法やエコシステムとの距離を広げない。

関数・クラスの宣言、引数、型注釈、特殊メソッド、デコレーターも元のPythonの規則に従う。`関数` / `クラス` 以外の語を勝手に翻訳しない。

## 曖昧性の解消

`戻す(x)` は名前の呼び出し、`戻す (x)` はreturn。空白は一部の日本語構文の判定に使われる。英語のif/for/while等のヘッダは後置形として再解釈しない。文字列・f-string・コメント中の構文語も翻訳しない。

複数行の式は許可するが、移動・削除する区切り自体をまたぐ改行は認めない。物理行の対応を保証し、CPythonの列診断の完全な逆変換はv0.1では保証しない。以前の曖昧な列位置保証を実装可能な保証範囲に明確化する。

## 維持する契約

compileはPythonファイルへの変換のみ、runは変換済み.pyを書き出さないCPython実行。言語変換は共通とし、出力・副作用の契約を入れ替えない。PyInstaller/Nuitkaにはcompileの生成物を渡す。import hookや専用ランタイムを追加しない。

旧テストを削除せず、新しい構文と境界条件のテストを追加する。文法の決定は、正式リリース、全環境でのパッケージング保証、ライセンス決定を意味しない。

## 読みやすい日本語への語彙統一

`try` は既存の平易な `試す` を維持する。`試行` という不要な熟語に変えない。`except` は `例外処理`、`raise` は `例外を起こす` を新しい正式表記とする。`finally` は `最後に` を維持する。`例外を送出` と `最終処理` は採用しない。`捕まえる` と `投げる` は既存コード用に残す。例外送出の `from`、例外の別名指定に使う `として`・`と名付ける`・`as` の意味は変わらない。

`return` の正式表記を `返す` / `値 を返す` に統一する。旧表記 `戻す` / `値 を戻す` は互換のため残す。自然な日本語にする変更でも、構文に新しい実行意味や独自ランタイムを追加しない。`break` は `繰り返しをやめる`、`continue` は `繰り返しを続ける` を正式表記とする。旧 `抜ける` / `続ける` は既存ソース互換のため残す。

## ループ制御の対象を明確にする

`繰り返しをやめる` はPythonの `break`、`繰り返しを続ける` は `continue` に一対一対応する。後者は今の反復の処理を続行するのではなく、その回の残りを飛ばして次の反復に進む。いずれも `for` / `while`（`async for`を含む）の最も内側のループのみを対象とし、`if`・`try` の終了命令としては扱わない。`抜ける` と `続ける` は互換表記として残す。
