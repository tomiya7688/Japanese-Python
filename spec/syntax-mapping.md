# JPy ↔ Python 文法対応表

状態: **言語仕様の設計表**。表記決定と変換器への実装は別々に管理する。
基準: Python 3.12。Pythonの実行意味・評価順・スコープ・例外・構文上の制限を変更しない。
標準ライブラリ、組み込み関数、型・属性・メソッドの**名前**は翻訳しない。関数定義・呼び出しなどの**文法**は対象。
記号・括弧・インデントはPythonと共通。英語のPython構文も引き続き有効。

凡例: **既決**＝従来決定済み、**新決**＝直観的な表記として今回決定、**要検討**＝日本語表記未決定。これらは実装完了を意味しない。

## 実装・検証上の注意

- **新決は表記上の決定であり、現行の変換器で動作する保証ではない。** 実装とテストは別コミットで行う。
- `真`、`偽`、`なし`、`かつ`、`または` などはPythonでは合法な識別子にもなるため、文脈依存の認識と互換性方針が必要。単純な全テキスト置換は禁止。
- f-stringの式部分、内包表記、括弧内、パターン、型注釈等でも、文法上合法なら同じ表記を使えるようにする。
- Pythonの構文を完全に列挙して対応漏れを検査するため、[全面対応要件](full-grammar-coverage.md)と[Python 3.12公式文法](https://docs.python.org/3.12/reference/grammar.html)を参照する。
- 既存の日本語表記とPython表記は維持する。compileは.pyを生成するだけ、runは.pyを生成せずCPythonで実行する。PyInstaller/Nuitkaにはcompile生成物を渡す。
