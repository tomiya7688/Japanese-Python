# Japanese-Python (JPy)

> **Pythonの基本文法をすべて日本語で書けるようにする言語変換仕様。** 変換器は仕様を実装・検証するための補助ツールです。

## 基本文法の全面対応が必須

**英語でも書ける。ただし、英語でしか書けない言語構文は残さない。** 現在の基準であるPython 3.12の文・式・パターンとその組み合わせをすべて日本語対応の対象とします。非同期処理、生成器、内包表記、論理演算子、定数、スコープ宣言等も対象です。

対応範囲と完了条件は **[基本文法の日本語全面対応要件](spec/full-grammar-coverage.md)** を優先します。[既存構文仕様 v0.1](spec/JPy-v0.1.md)と過去の決定記録に残る「一部は英語表記のみでよい」という対象外方針は、この要件で撤回しました。既存の日本語表記は維持します。

**現在は部分的な仕様・参考実装です。全面対応済みではありません。** 以下は決定済み部分の例であり、未決定・未実装の部分を英語で補うことを、日本語対応の完成として数えません。

式の優先順位・評価順・動作はPythonのままで、式のキーワードにも日本語表記を用意する方針です。Pythonの記号記法、ライブラリAPI、型注釈の意味、インデントは維持します。元の `if` / `elif` / `for` / `while` 等も使えます。独自VMや独自型システムは作りません。

```jpy
関数 判定(点数: int) -> str:
    もし 点数 >= 80 ならば:
        "優秀" を返す
    それ以外でもし 点数 >= 60 ならば:
        "合格" を返す
    それ以外:
        返す "不合格"

繰り返し 点数 を [50, 65, 80] から:
    print(判定(点数))

繰り返し i が 0 から 5 まで 2 ずつ:
    print(i)  # 0, 2, 4。終了値5は含まない

i = 0
i < 3 の間:
    i += 1
```

## 決定済みの文法（一部）

| 用途 | 正式な日本語表記 |
|---|---|
| 条件分岐 | `もし 条件 ならば:` / `それ以外でもし 条件 ならば:` / `それ以外:` |
| 汎用for | `繰り返し 対象 を 式 から:` |
| 範囲for | `繰り返し i が 開始 から 終了 まで [増分 ずつ]:` |
| while | `条件 の間:` |
| match / case | `対象 に応じて:` / `パターン の場合:` / `パターン の場合 もし 条件 ならば:` |
| 関数・クラス | `関数` / `クラス` |
| 戻り値・制御 | `返す` / `値 を返す` / `繰り返しをやめる` / `繰り返しを続ける` / `何もしない` |
| import | `読み込む モジュール [として 別名]` |
| 選択import | `モジュール から 名前 を 読み込む [別名 として／と名付ける]` |
| 例外処理 | `試す:` / `例外処理 例外 として 名前:` / `最後に:` / `例外を起こす 例外` |
| with / assert | `使う 式 として 対象:` / `確認する 条件, メッセージ` |

表の `[...]` は省略可能を表すメタ表記です。`range` と同じく **終了値は含みません**。増分省略時は1で、降順には負の増分を指定します。

```jpy
繰り返し i が 0 から 10 まで:
    もし i == 3 ならば:
        繰り返しを続ける  # 今回の残りを飛ばして次へ
    もし i == 7 ならば:
        繰り返しをやめる  # 最も内側のループを終了
    print(i)
```

`繰り返しをやめる` はPythonの `break`、`繰り返しを続ける` は `continue` と同じです。両方ともfor/while/async forのループ内部でのみ使え、条件分岐や例外処理の専用脱出文ではありません。

### `として` と `と名付ける` は両方使えます

当面、表中の `として` は **`と名付ける` または英語の `as` と同義**です。日本語形の `読み込む`・`例外処理`（旧 `捕まえる` も可）・`使う` の同じ位置で使え、どれも同じPythonに変換します。どちらの日本語表記も非推奨にはしません。

```jpy
読み込む math として 数学
読み込む math と名付ける 数学
読み込む math as 数学
```

上の3文は、それぞれ `import math as 数学` に変換されます。

**選択読み込み**（Pythonの `from ... import ...`）は次の形です。

```jpy
math から sqrt を 読み込む
math から sqrt を 読み込む 平方根 として
math から sqrt を 読み込む 平方根 と名付ける
```

後ろの2つはいずれも `from math import sqrt as 平方根` に変換します。従来の通常importにおける別名指定の語順は変更しません。元のPythonの `from ... import ... as ...` も使用できます。`例外処理 ValueError と名付ける エラー:` や `使う 式 と名付ける 対象:` も使えます。`と名付ける` は一つの語として前後を空白で区切り、一つの指定箇所で `として と名付ける` のように重ねません。詳細は [仕様 §4.9](spec/JPy-v0.1.md#49-として--と名付ける--as-の併用) を参照してください。

**新しいコードでは `返す` / `を返す`、`試す` / `例外処理` / `例外を起こす` / `最後に`、`繰り返しをやめる` / `繰り返しを続ける` を使います。** `戻す` / `を戻す`、`捕まえる`、`投げる`、`抜ける`、`続ける` は互換表記です。`試行`、`例外を送出`、`最終処理` は採用しません。`各 対象 を 式 から:`、`条件 なら:` も互換表記として維持します。詳細・制約・採用理由は [文法決定記録](docs/grammar-decisions-v0.1.md) と [既存構文仕様](spec/JPy-v0.1.md) にあります。対応範囲に関する古い除外規則は [全面対応要件](spec/full-grammar-coverage.md) で置き換えています。

### 残る部分も対象外にはしません

`async` / `await`、`yield` / `yield from`、`lambda`、`del` / `global` / `nonlocal` / `type`、`except*`、論理演算子・定数、条件式、内包表記、相対・複数・ワイルドカードimport、複数項目のwith、パターン内部のas、例外原因のfrom等にも日本語表記を用意することを必須とします。

括弧内、引数、型注釈、内包表記、f-stringの埋め込み式など、構文が合法な位置で組み合わせられる必要があります。文字列やコメントそのものは翻訳しません。記号や `print` / `range` / `__init__` 等のAPI・名前は、英語の構文キーワードとは別に扱います。

未決定・未実装の構文を、現在の参考ツールがすでに受理するとみなさないでください。[対応一覧と完了条件](spec/full-grammar-coverage.md) に従って未完了として管理します。

## パターンで場合分け

```jpy
データ に応じて:
    {"名前": 名前, "年齢": 年齢} の場合 もし 年齢 >= 18 ならば:
        print(名前, "成人")
    [先頭, *残り] の場合:
        print(先頭)
    _ の場合:
        print("その他")
```

`match` は単純な値の比較ではなく、Pythonの構造的パターンマッチです。日本語の文法は変換後の `match` / `case` / `if` の意味を変えません。

## 2つのコマンドの役割は不変

| | `jpy compile` | `jpy run` |
|---|---|---|
| 役割 | 通常の `.py` を生成するだけ | `.jpy` を対象としてCPythonで実行 |
| `.py` 出力 | する | しない。一時ファイルにも出さない |
| アプリケーション実行 | しない | する |
| JPyへの依存 | 生成物には不要 | 起動時に参考ツールを利用 |
| 配布ツールの入口 | 生成した `.py` | 使用しない |

`run` はメモリ内で同じ変換規則を適用し、同一CPythonプロセスで `compile` / `exec` します。未変換の日本語ソースをCPythonが解釈するわけではありません。アプリケーション自身のファイル出力は別であり禁止しません。

## 導入と試用

参考実装の検証対象は **CPython 3.12 / 3.13** です。新しいPythonバージョンへの無条件の互換性保証はしません。

```sh
python -m pip install -e .

jpy compile examples/hello.jpy -o build/hello.py
python build/hello.py

jpy run examples/hello.jpy
jpy run examples/grammar.jpy
python -m japanese_python run examples/grammar.jpy
```

引数は `jpy run main.jpy -- arg1 arg2`。既存の出力を上書きする場合だけ `jpy compile ... --force` を指定します。

### 日本語の構文語と識別子

構文語と式は半角スペース等で区切ります。`返す(x)` は名前「返す」の関数呼び出し、`返す (x)` はreturnです。`返す = 1` のような代入も使えます。ただし `返す` 単独の文はreturnになるため、Pythonソースすべての厳密な上位集合ではありません。旧表記 `戻す` にも同じ認識規則を適用します。

エラーのファイル・行の対応を保ちます。CPythonが返す列番号・下線については、変換後の位置になる場合があります。

## PyInstaller / Nuitka

**先にcompileし、生成した通常の `.py` を入力します。** runをビルド用の入口にせず、専用ランタイムを生成物に注入しません。

```sh
jpy compile examples/hello.jpy -o build/hello.py --force
python -m PyInstaller --onefile --name hello build/hello.py
python -m nuitka --mode=standalone build/hello.py
# standaloneで検証してから
python -m nuitka --mode=onefile build/hello.py
```

両パッケージャーは別途導入が必要です。依存 `.jpy` も事前に `.py` に変換し、通常のPythonのモジュール配置を保ちます。全OS・全依存関係でのビルド成功を保証するものではありません。[配布ガイド](docs/packaging.md) を参照してください。
